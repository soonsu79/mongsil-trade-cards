# mongsil-trade-cards

몽실이 카드뉴스 자동 발행 시스템의 **이미지 전용 공개 저장소**입니다.

`mongsil-trade-autopublisher`(비공개 저장소)가 매일 생성하는 카드뉴스 PNG를 여기에
push해서, Threads API가 요구하는 공개 raw URL(`raw.githubusercontent.com/...`)로
노출시키는 용도로만 씁니다. 이 저장소에는 카드 이미지 외 다른 파일(코드, 시크릿 등)을
절대 넣지 않습니다.

이미지는 `cards/<YYYY-MM-DD>/카드01.png` ~ `카드08.png` 형태로 쌓입니다.
